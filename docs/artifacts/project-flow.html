paper-rag Project Flow

Search from a project, triage, ingest into the main pool once — then the project mirrors its accepted papers by symlink and copied vectors. Planned commands (PLAN-projects.md), example project asd-cortex.

Pipeline

1

Create project project

Scaffolds the mini-home layout anywhere you choose and registers it in ~/.config/paper-rag/projects.json, pinned to the current main home.

/paper-rag:project create asd-cortex --path ~/Research/asd-cortex/papers
2

Run a PubMed search inside the project project

Same engine and flags as /paper-rag:pubmed-search, but results land in the project, not the main home:

/paper-rag:project search asd-cortex --mode concepts --concepts '[
  {"name": "autism", "terms": ["autism spectrum disorder"]},
  {"name": "cortex", "terms": ["cortical thickness", "surface area"]}
]' --sensitivity balanced

Writes <project>/searches/2026-09-30_1420_autism-cortical-thickness/ with query.json, pmids.txt, result.json, triage.html; logs to <project>/search_log.jsonl.

3

Triage in the browser project

Open the search's triage.html, keep/reject each paper; decisions save to triage.json in the same search dir. Unchanged from today's triage.

python scripts/triage.py ~/Research/asd-cortex/papers/searches/2026-09-30_1420_autism-cortical-thickness --serve
4

Ingest accepted papers into the main pool main home

Reads the search's triage.json and runs the normal ingest into the main library — full text, figures, chunks, embeddings, BM25. Papers are stored exactly once. Accepted doc_keys are recorded in the project's members.json, then sync runs automatically.

/paper-rag:project ingest asd-cortex searches/2026-09-30_1420_autism-cortical-thickness
5

Auto-sync builds the project mirror project

No new parsing or embedding — everything is derived from the main home (mechanism below). Re-runnable any time for repair:

/paper-rag:project sync asd-cortex
6

Search and browse the project only project

The project dir is shaped like a paper-rag home, so the existing hybrid retrieval and dashboard run against it unchanged:

/paper-rag:project ask asd-cortex "Is cortical thickness altered in ASD adults?"
/paper-rag:project dashboard asd-cortex --serve

Sync mechanism: how project papers are symlinked

Symlink details. One symlink per accepted paper, directory-level: papers/pmid_31173064 → ~/.local/share/paper-rag/papers/pmid_31173064. Existing readers (scan_papers(), BM25 rebuild, query.py) follow symlinks transparently on macOS. If a paper is later removed from the main library, the next sync prunes the dangling symlink, its member entry, and its chunks from the project indices, with a warning in the sync summary.

Papers already in the library skip steps 2–4: /paper-rag:project add asd-cortex 31173064 adds membership and syncs.
